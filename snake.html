How this race works

One move = one decision

Each snake advances one cell per decision. A decision costs that variant's measured mean latency, so the snake's on-screen speed is set by real inference time — not a guess.

Five variants, one clock

All five panels run on a single shared clock. MedJev, AR-Gen, AR-LL, AR-Head, and NAR each steer toward the apple on their own; the fastest path pulls ahead because its decisions are cheaper.

One apple at a time

Only one apple is on the board at once. A new one appears only after the current one is eaten, so every apple is a real decision the snake must make.

Speed is rescaled

On-screen speed is compressed into a readable range so the slowest snake is still visible. The ms/decision shown on each panel and in the leaderboard are the real measured numbers.
