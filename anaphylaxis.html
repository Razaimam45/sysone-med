How this race works

The door is the deadline

The airway closes continuously. Patency falls from 100% to 0% over the closure time. Below 25% it's critical; at 0% the patient codes.

Epinephrine must beat the door

Each path injects at its measured mean latency. If it lands while the airway is still open, it saves the patient; if the door shuts first, it's a code blue.

Confidence is real

Every injection carries the path's measured confidence. The stream logs confidence, latency, and whether it beat the closing door.

Speed the closure to test

Drag the closure time. At 600 ms only the fast paths get the shot in; at 3000 ms even the slowest autoregressive path makes it. The spread is the story.
