How this game works

One alarm = one call

An alarm slides toward the decision line. The right move is ACT for a true alarm, HOLD for a false one — the same read a clinician makes at the bedside.

Speed and accuracy both count

Each model decides at its measured latency. If it's slower than the window it's too late and the call is wrong. If it's in time, it's correct only with its measured accuracy.

The stability bar

A correct call nudges stability up; a wrong or late call drains it. A low-accuracy model survives a few alarms before flatlining — it doesn't die on the first miss.

Widen the window to test

At 400 ms the slow autoregressive path is always too late. Drag to 2000 ms and even it gets a shot — but its accuracy still decides how long it lasts.
