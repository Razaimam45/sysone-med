How this race works

One case = one decision

A critical case appears with a closing treatment window. Each path must pick the right intervention — the same call a clinician makes under pressure.

Speed decides the outcome

Each path takes its measured mean latency to decide. If it finishes before the window shuts, it saves the patient; if it's too slow, the window closes first.

Confidence is real

Every call carries the path's measured confidence. The stream logs the action, confidence, latency, and whether it made it in time.

Widen the window to test

Drag the treatment window. At 400 ms only the fast paths make it; at 2000 ms even the slowest autoregressive path squeezes in. The spread is the story.
