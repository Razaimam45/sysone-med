\abstract{
Large vision--language models (VLMs) answer bounded medical questions the same way they answer open-ended ones: by decoding an answer one token at a time. Typesafe's recent \textbf{Jev} release reframed this as unnecessary for tasks where the candidate answers are already known, exposing a typed, probabilistic \textbf{System One} decision directly instead of a generated string. Jev, and the wave of follow-on systems it triggered (Jevify, Kev, MedJev, Laya), each change several things about the inference pipeline at once relative to a standard autoregressive (AR) baseline -- whether decoding happens, whether the decision interface is learned, and which backbone produces it -- so none of them tells us which change is actually responsible for their reported gains. 
%
Recent work has explored several ways to make these bounded decisions: generate and parse an answer, read candidate-label likelihoods from an AR model, learn a head over AR representations, or predict directly with a NAR encoder. Medical SysOne organizes these developments into a taxonomy and compares representative medical implementations across seven QA/VQA benchmarks, separating matched within-backbone contrasts from comparisons of complete systems.
%
We evaluate accuracy, latency, probability quality, errors, image dependence, and post-hoc selection. Native label scoring preserves AR-Gen's observed decisions at substantially lower measured latency; learned heads improve accuracy and probability quality, while representation adaptation can worsen calibration. NAR decisions are fast but task-dependent. These findings clarify design trade-offs for efficient, uncertainty-aware medical assistants, without establishing clinical readiness.
}
